สต็อกเสี่ยงและข้อสังเกต

นิยาม ยอดยกมา = คงเหลือต้นช่วง · รับ = รับเข้าคลังในช่วง · จ่าย = จ่ายออกในช่วง · คงเหลือ = ยอดปลายช่วง (ยกมา + รับ − จ่าย) มูลค่าเป็นบาท ปริมาณเป็นหน่วยนับของแต่ละรายการ (เม็ด ขวด แอมพูล ฯลฯ) จึงรวมข้ามหน่วยไม่ได้ ระบบแสดงปริมาณทีละหน่วยนับ

การรวมช่วงเวลา เมื่อเลือกหลายเดือน: ยกมา = ยกมาของเดือนแรก · รับ/จ่าย = ผลรวมทุกเดือน · คงเหลือ = คงเหลือสิ้นเดือนสุดท้าย (ไม่ใช่ผลรวม) · วันที่สต็อกพอใช้ = คงเหลือสิ้นช่วง ÷ อัตราจ่ายต่อวันเฉลี่ย 3 เดือนล่าสุดที่มีข้อมูล (มีเดือนเดียวใช้ 1 เดือน) · อัตราหมุนเวียน = จ่าย ÷ สต็อกเฉลี่ย (ยกมา+คงเหลือ)/2 ปรับเป็นต่อปี ค่าเหล่านี้เป็นตัวชี้วัดเบื้องต้น ยิ่งมีหลายเดือนยิ่งน่าเชื่อถือ

สถานะรายการ หมดสต็อก = คงเหลือ 0 แต่มีการจ่าย · ใกล้หมด = พอใช้ไม่ถึง 30 วัน · ล้นสต็อก = พอใช้เกิน 180 วัน · ไม่เคลื่อนไหว = มีของแต่ไม่มีการจ่ายในช่วง

ABC จัดชั้นตามมูลค่าที่จ่ายในช่วงที่เลือก เรียงมากไปน้อย: A = รายการที่ทำให้มูลค่าจ่ายสะสมถึง 80% · B = 80–95% · C = ที่เหลือ · ไม่จ่าย = ไม่มีการจ่ายในช่วง

มูลค่า คิดเป็นราคาต้นทุน ตามคอลัมน์มูลค่าในรายงานคลัง (ไม่ใช่ราคาขาย) · จำนวนรายการ นับเฉพาะรายการที่มีสต็อกหรือเคลื่อนไหวในช่วงที่เลือก (แสดง “เคลื่อนไหว / ทั้งหมด”) · รายการที่ติดป้าย “ตรวจข้อมูล” มีราคาต่อหน่วยสูงผิดปกติเทียบกับรายการหน่วยเดียวกัน ควรตรวจหน่วยนับ/ขนาดบรรจุกับต้นฉบับ

หมวดสินค้า ตามรหัสหมวดในรายงานคลัง (ยาในบัญชียาหลักแห่งชาติ, ยานอกบัญชี, วัสดุเภสัชกรรม, ยาสนับสนุน, เวชภัณฑ์มิใช่ยา) · กลุ่มโรค จัดจากชื่อยาตามกฎเดียวกับ dashboard การใช้ยา ยาใช้ร่วมหลายโรคและวัสดุทางการแพทย์ควรให้เภสัชกรทบทวน
