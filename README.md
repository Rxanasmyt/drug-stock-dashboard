# Dashboard คลังยาและเวชภัณฑ์ รพ.กรงปินัง

ยอดยกมา / รับ / จ่าย / คงเหลือ (ปริมาณและมูลค่า) แยกตามหมวดและกลุ่มโรค · มีแท็บ "สั่งซื้อวันนี้" ส่งออก Excel (CSV) ได้ · ใช้ GitHub Pages ติดตั้งเป็นแอปได้ (PWA)

**ข้อควรระวัง:** repo เป็นสาธารณะ ไฟล์ใน `data/` และ `data.js` ทุกคนเปิดดูได้

## เปิดใช้งาน (ทำครั้งเดียว)
Settings → Pages → Deploy from a branch → `main` / `(root)`
ลิงก์: https://rxanasmyt.github.io/drug-stock-dashboard/

## อัปเดตรายเดือน (ไม่ต้องเขียนโค้ด)
1. ตั้งชื่อไฟล์รายงานคลังให้มีเดือน-ปี พ.ศ. เช่น `รายงานคลัง-11-2569.xls`
2. เข้า repo → โฟลเดอร์ `data` → Add file → Upload files → Commit
3. รอประมาณ 1–2 นาที GitHub Actions จะสร้าง `data.js` ใหม่ให้เอง (ดูสถานะที่แท็บ Actions) แล้วรีเฟรชหน้าเว็บ
- เก็บไฟล์ของทุกเดือนไว้ในโฟลเดอร์ `data` (ระบบรวมทุกเดือนเข้าด้วยกัน) ห้ามมีไฟล์เดือนซ้ำ
- ใช้ในเครื่องแทนได้: `pip install xlrd` แล้ว `python3 update.py`
- ถ้ารายงานขึ้นแดง: ดู log ที่แท็บ Actions — ข้อความเป็นภาษาไทยบอกสาเหตุ (เช่น อ่านเดือนจากชื่อไฟล์ไม่ได้)

## เกณฑ์ที่ใช้
สต็อกต่ำ < 30 วัน · เกิน > 180 วัน · DOS = คงเหลือ ÷ อัตราจ่ายเฉลี่ยต่อวัน (สูงสุด 3 เดือนล่าสุด) · ABC ตามมูลค่าจ่าย (A 80%, B 95%) · รายละเอียดดูที่ปุ่ม "วิธีคำนวณ" ท้ายหน้า

## โครงสร้าง
`index.html app.js shim.js d3.min.js` = ตัวเว็บ · `data.js` = ข้อมูล (สร้างอัตโนมัติ) · `tools/` = ตัวแปลงรายงาน · `update.py` = สั่งแปลง
